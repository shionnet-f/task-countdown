# Task Countdown

Googleカレンダーを開く心理的負荷を減らすために、「今やること」と「終了までの残り時間」をすぐ確認できるWebアプリです。

---

## Background

Googleカレンダーで時間単位のスケジュール管理をしているが、開始/終了の確認のために毎回カレンダーを開くのが負荷になってきた。

## Goal

デスクトップ/スマホのホームに置き、カレンダーを開かずに「今やること」と「残り時間」を把握できるようにする。

---

## ユーザ分析（ミニ）

### 想定ユーザ

- 時間単位で予定・タスクを管理している学生（自分）
- Googleカレンダーを使っているが、確認のために毎回開くのが負荷

### Pain（困りごと）

- 「今やること」「終了までの残り時間」を確認するたびに  
  カレンダーを開く → 該当予定を探す → 閉じる、が発生し心理的負荷が高い
- 負荷のせいで確認頻度が下がり、時間の意識が薄れる

### Job（やりたいこと）

- 1秒で「今やること」と「残り時間」を把握したい
- 開始/終了の節目を認識して、次の行動に切り替えたい

### Success（成功条件）

- ホーム/デスクトップから即確認できる
- 入力や操作が迷わない（最小ステップ）
- 残り時間が正しく動く（表示の信頼性）

---

## 階層的タスク分析（HTA：MVP1までの全体像）

### 0. ゴール

残り時間を把握し、行動を開始・維持・終了（切替）できる。

### 1. モードを選ぶ（最上位の分岐）

1.1 **シンプルタイマー**を使う  
1.2 **ワンタッチ・ポモドーロ**を使う  
1.3 **Googleカレンダー連携**でカウントダウンを表示する

**Plan 0:** ユーザは状況に応じて 1.1〜1.3 のいずれかを選ぶ。

### 2. 1.1 シンプルタイマー（MVP0の核）

**ゴール：手入力で残り時間を表示する**

2.1 タスクを設定する

- 2.1.1 タスク名を入力する
- 2.1.2 終了時刻（HH:MM）を入力する（※MVP0は「今日の時刻」として扱う）

  2.2 実行する

- 2.2.1 Start を押す
- 2.2.2 残り時間を確認する（常時表示）
- 2.2.3 Stop / Resume で一時停止・再開する（任意）

  2.3 終了・切替

- 2.3.1 0になったことを認識する（Finished表示）
- 2.3.2 Reset して次のタスクへ切り替える

### 3. 1.2 ワンタッチ・ポモドーロ（MVP1候補）

**ゴール：入力ゼロで開始し、作業/休憩を自動で回す**

3.1 モードを選ぶ（例：25/5、50/10）  
3.2 ワンタッチで開始する  
3.3 フェーズ遷移（作業 → 休憩 → 作業…）  
3.4 通知/音（任意）  
3.5 終了・スキップ・リセット

**Plan 3:** 最初は 25/5 固定でも良い（「ワンタッチ」の価値＝入力ゼロを優先）。

### 4. 1.3 Googleカレンダー連携（MVP1〜MVP2）

**ゴール：カレンダーを開かずに次の予定と残り時間を表示する**

4.1 認証する（OAuth）  
4.2 次の予定を取得する  
4.3 予定情報を表示する（タイトル、開始/終了、場所など）  
4.4 予定終了までの残り時間を表示する  
4.5 予定が切り替わったら自動更新する  
4.6 エラー時の代替（手入力モードへ戻す）

  - タスク名＋終了時刻の手入力
  - 残り時間カウントダウン
  - Finished表示、Stop/Reset
