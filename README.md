# Task Countdown

Googleカレンダーを開く心理的負荷を減らすために、タスク表示と終了までのカウントダウンを見られるWebアプリ。

## Background
Googleカレンダーで時間単位のスケジュール管理をしているが、開始/終了の確認のために毎回カレンダーを開くことが負荷になってきた。

## Goal
デスクトップやスマホのホームに置き、カレンダーを開かずに「今やること」と「残り時間」を把握できるようにする。

## MVP
### MVP0（最短で完成）
- 手入力で「タスク名 + 終了時刻 / 残り時間」を設定
- 終了までのカウントダウンを表示

### MVP1（本命）
- Googleカレンダー連携で「次の予定」を取得
- 予定情報 + カウントダウンを表示（認証が入るため後回し）

## Tech Stack
Next.js + TypeScript
